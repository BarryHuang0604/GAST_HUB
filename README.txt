GSAT HUB v3.6 極簡學習版

部署方式：
1. 解壓縮 ZIP。
2. 將 index.html、app.js、style.css、firebase-config.js、firestore.rules、vocabulary.json 上傳到 GitHub Repository 根目錄。
3. GitHub Pages 開啟後，使用原本 Firebase 帳號登入。
4. 若瀏覽器顯示舊版，請強制重新整理。

功能：
- 移除歷屆試題、成績分析、三人排行的畫面入口。
- 英文單字分 Level 1–2、3–4、5–6 三階，20 個新字為一關，可跳階。
- 關卡底色依該關所有單字的平均熟悉程度逐漸加深。
- 單字卡、選擇測驗、到期複習；答錯自動加入錯題本（同一字不重複新增）。
- 錯題本可新增、編輯、刪除、翻答案複習。
- 保留讀書計畫與共享筆記。

注意：
- 刪除歷屆試題等功能是從網站介面與程式移除，不會清除 Firebase 既有作答紀錄。
- 錯題複習會記錄已複習次數，並不會自動刪除錯題。
- 原單字資料仍可能有未校對完成的字義，請以官方原始資料為準。
- 大量單字進度目前仍保存在使用者 Firestore 文件，長期使用可能遇到文件大小上限；未來宜改用子集合。
- 已檢查 JavaScript 語法與壓縮檔，尚未實際登入 Firebase 端對端測試。

關卡單字順序：每階以固定種子打亂，不依照 JSON 字母順序。相同單字在同一階只會出現一次；重新整理、重新登入不會變更關卡內容。
